## 6. Shuffle algorithm — PASS

- Per-context Fisher–Yates queues
- Recently played history per playlist plus bounded global history
- No immediate repetition when another track is available
- Full-pool use before reshuffle
- Sequential no-repeat fallback when shuffle is off
- Track `ended` events select the next valid track indefinitely
- Context changes preserve controlled randomness; returning to a context retains its history

## 7. TTS architecture — PASS

- Central `AudioManager.playVoice()` uses the browser/device `speechSynthesis` engine.
- Utterances are serialized in one queue and are not cancelled by newer chat messages.
- Music ducks on utterance start and restores on end/error.
- Voice/TTS is opt-in by default to prevent duplicate TalkBack plus TTS output.
- Music, SFX, voice, volume, and shuffle settings persist in local storage.
